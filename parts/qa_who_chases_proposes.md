# Q&A — 谁追谁？谁求婚？

**问题：** 她会追伴侣/向他求婚，还是他来追她/求婚？

---

## 她会追他吗？

**不会大力追，但会发出信号。**

| 指标 | 说明 |
|------|------|
| Venus逆行H7 | 逆行金星的人不向外追，是向内感受、等待被靠近 |
| Ketu H7 | Ketu不积累，不追逐——是完成型能量，不是猎取型 |
| 自我怀疑（Rahu H1）| 她不确定自己值不值得，所以不会主动出击 |
| Mars旺势在H10，不在H7 | 她的进攻性能量全放在职业上，不在感情上 |

但——Mercury AK会做一件事：当她决定了，她会执行。她不会"追"，但她会在时机成熟时把模糊的东西变成明确的——不是表白，是说清楚。

---

## 他会追她吗？

**也不会大力追，但他会持续出现。**

| 指标 | 说明 |
|------|------|
| DK太阳天秤 | 天秤不冲动，完全确定之前不会出牌 |
| Saturn H8 | 慢、深、审慎——需要充分评估才会行动 |
| Jupiter逆行Aquarius | 内部处理很久才会外部表达 |

他不会"追"，但他会在她的轨道里稳定出现，做有实质意义的事，然后等她接收到信号。

---

## 真实的发展顺序

```
1. 专业场合反复出现在同一个轨道
       ↓
2. 她先发出信号（持续的互动质量、专注、Mercury AK点到为止）
       ↓
3. 他接收到信号，内部评估（Saturn + Jupiter逆行 = 评估期长）
       ↓
4. 他确认后，做出DK太阳式的正式表态
       ↓
5. 她用Mercury AK确认、决定、推进
```

---

## 求婚是谁？

**他来求婚。**

DK太阳 = 尊严和仪式感。当他确定了，他不会等她来问——他会用他认为合适的方式做这件事，因为这关系到他的dignity。

**但她需要先让他知道她准备好了。**

DK太阳天秤不会在不确定对方意愿的情况下冒险——他需要她发出足够清晰的信号，然后才会正式表态。

---

## 一句话总结

> **没有人追谁。她的职业磁场吸引他靠近，他的持续出现让她感受到重量，Mercury AK说出那句话，DK太阳做出正式的姿态。这是两个慢热的人，轨道交叉后自然引力的故事。**
